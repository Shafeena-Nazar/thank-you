# Thank-you site

Static site: open `index.html`, or publish with GitHub Pages (Settings > Pages > deploy from `main` branch, root folder).

- Edit your name, tenure, title, messages and contact link in `data.js`.
- Add a photo for someone: copy it into `images/` and add `photo: "name.jpg"` to their card in `data.js`.
- The page has a `noindex` tag so search engines skip it. That is a request, not real privacy.
